# Поиск сигнала

Версия 0.6: исправлен пустой график: оценки точек 0–4 теперь показаны подписанными столбцами. Графитовая тема с белым акцентом без зелёных оттенков. Одноцветный знак антенны уменьшен внутри адаптивной иконки.

Небольшое Android-приложение для поиска точки под LTE-роутер. Выбор активной SIM показан отдельными кнопками. Основной экран показывает LTE-диапазон, простую оценку качества приёма, причину оценки, численные RSRP/RSRQ/SNR и время последнего обновления. «Запомнить эту точку» предлагает дать ей имя и добавляет её в график (оценка от 0 до 4). Сохранённые точки можно переименовать или удалить с подтверждением. Измеренные значения при переименовании не меняются. Точки хранятся на телефоне отдельно по выбранной SIM и остаются после закрытия приложения. Точки из версии 0.2 без названия получают имя «Точка N». «Проверить скорость» скачивает до 10 МиБ с Cloudflare **только по прямому мобильному соединению** (без Wi-Fi и VPN); во время скачивания показывает среднюю скорость с начала теста и объём загруженного. Результат скорости не участвует в оценке радиосигнала.

## Использование

1. На телефоне вставить проверяемую SIM, включить геолокацию и разрешить приложению доступ к местоположению и состоянию телефона.
2. На главном экране выбрать нужную SIM. Если виден 5G, переключить предпочтительную сеть на 4G в системных настройках: сравнивать с LTE-роутером измерения 5G нельзя.
3. В каждой точке подержать телефон неподвижно 20–30 секунд; смотреть на время обновления и оценки. Нажать «Запомнить эту точку» и ввести понятное название, затем двигаться дальше. График и список показывают сохранённые результаты только выбранной SIM. Под каждой точкой есть кнопки «Название» и «Удалить».
4. После отбора кандидатов выключить Wi-Fi и VPN и по желанию выполнить тест скорости. Если Cloudflare недоступен при ограничениях оператора, приложение сообщит об ошибке; это не означает плохой уровень сигнала. Тест расходует до 10 МиБ мобильного трафика.

Оценки — ориентиры для отбора точек, а не обещание скорости. Телефон и роутер имеют разные антенны; окончательную проверку делать на роутере. Приложение ничего не загружает на сервер и не отправляет телеметрию. При проверке скорости оно только загружает тестовые данные с `speed.cloudflare.com`.

## Сборка

Открыть корневую папку в Android Studio с установленными Android SDK 35 и JDK 17. Проект использует Android Gradle Plugin 8.9.2; для сборки нужна версия Gradle 8.11.1. Через Android Studio: **Build → Build APK(s)**; или `gradle assembleDebug` при наличии Gradle 8.11.1. APK: `app/build/outputs/apk/debug/app-debug.apk`.

Debug APK собран в рабочей среде с Android SDK 35, JDK 17 и Gradle 8.11.1. Запуск на Xiaomi 15 и корректность радиопоказаний на этом устройстве пока не проверены.
